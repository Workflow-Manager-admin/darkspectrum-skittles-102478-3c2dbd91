# Scribbles Clothing & Accessories React Template

A lightweight, modern React template powering Scribbles—a creative fashion and accessories shop.

## Features

- **Fashion-Forward UI**: Clean, sophisticated design inspired by creative apparel & accessories brands
- **Modern**: Dark glassmorphic backgrounds with glowing accent colors
- **Responsive**: Seamlessly adapts to all device sizes for shopping on-the-go
- **Simple**: Easily extensible for your own collections

## Getting Started

In the project directory, you can run:

### `npm start`

Runs the app in development mode.  
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.  
It optimizes for size and performance.

## Customization

### Colors & Theme

Main Scribbles fashion brand colors are defined in `src/App.css` with variables.

### Components

Key components reside in `/src/components` and `src/pages`:
- Navbar (with logo & navigation)
- Home hero with fashion-themed imagery
- Product listing and detail cards
- Shopping bag/cart

Typography and design choices reinforce a modern retail apparel brand.
